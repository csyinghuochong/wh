当前物理/法术判定：SKILL_DAMAGE_CHECK_PHYSICS / SKILL_DAMAGE_CHECK_MAGIC。
默认值来自单位初始属性，不是在公式里再额外加一次：
暴击率 0.05
命中率 0.95

自身暴击 和  命中配置的都是固定值 但是这要/1000
技能编辑器上配置的值要 / 10000

属性初始值：命中 950、暴击 50，分别对应 95%、5%。
等级项 = 二次项 * Lv² + 一次项 * Lv + 常数项，Lv 为本函数的技能等级参数。
可否暴击=true 时：
    真实暴击率 = (自身暴击 + 暴击等级项 - 对方抗暴) / 1000 + 暴击加成 / 10000
可否闪避=true 时：
    真实命中率 = (自身命中 + 命中等级项 - 对方闪避) / 1000 + 命中加成 / 10000
可否闪避=false 时跳过闪避判定，不影响暴击和重击判定。
普通命中且可否重击=true 时：
    真实重击率 = 0.05 + (自身重击 + 重击等级项 - 对方化解) / 1000 + 重击加成 / 10000

暴击等级项为参数 11～13，重击等级项为 14～16，命中等级项为 17～19。
【当前限制】上下文 level 固定为 1；需要其他等级时可显式配置数字，自动等级传递待接入。
【暂不处理】可否格挡（参数 7）保留定义，目前不参与判定。

rand ( 0 ≤ x ≤ 10000 ）
    如果 x ≤ 真实暴击率 * 10000 ，本次攻击暴击，否则不暴击
    如果 x ≤ 真实命中率 * 10000 ，本次攻击命中，否则被闪避    

当前实现先判闪避，再判暴击，再在普通命中时判重击，共用同一个随机数 x。
治疗判定 SKILL_DAMAGE_CHECK_HEAL 只使用施法者、目标、技能 ID、等级、可否暴击、暴击加成六项，
治疗暴击率 = (自身暴击 - 对方抗暴) / 1000 + 暴击加成 / 10000，不含等级多项式。
