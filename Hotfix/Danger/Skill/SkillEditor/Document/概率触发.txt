

CHANCE_TRIGGER 当前参数（下标从 0 开始）：
0 基础概率，单位 0.01%，默认 10000。3000 表示 30%。
1 是否受属性影响：0 否，1 软控，2 硬控，默认 0。

不受属性影响：最终万分率 = clamp(基础概率, 0, 10000)。
受属性影响：最终万分率 = clamp(基础概率 * max(0, 1 + 命中 / 1000 - 对方抵抗 / 1000), 0, 10000)。
clamp 表示限制上下限。若使用 0～1 的概率，则应先把基础概率除以 10000：
最终概率 = min((基础概率 / 10000) * max(0, 1 + 命中 / 1000 - 对方抵抗 / 1000), 1)。
不能把万分率 3000 直接和小数上限 1 放在同一个 min 中。

是否受影响     
  否
  是 - 软控 (  自身 180 /  对方184 )  
  是 - 硬控 (  自身 181 / 对方 185 ) 

命中取原施法者，抵抗取技能处理器当前目标。
BUFF 回调中即使 caster 是怪物（BUFF 持有者），命中仍取给它上 BUFF 的玩家。
