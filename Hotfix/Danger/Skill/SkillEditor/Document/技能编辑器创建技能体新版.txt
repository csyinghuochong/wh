技能体触发技能的逻辑调整一下

当前函数 CREATE_SUMMON 使用 24 个参数，以 DocEditor界面配置.xml 为准。
参数下标从 0 开始；最大持续时间（9）、作用间隔（10）单位均为毫秒。
运动类型（6）：0静止、1直线、2追踪。
追踪目标（7）：[无] 0 只表示不追踪，不会关闭四类关联技能。
运动类型为追踪且目标明确为“无”时保持出生位置；直线运动仍沿初始朝向移动。
其他运动类型仍按配置移动，持续时间、作用次数、关联技能照常执行。

技能体 有 4 个触发技能

最大持续时间 5200ms
作用间隔 1000ms
作用次数 5


Summon 表的

创建触发 = 0ms   			 初始技能  Skill_1
作用触发 = 1000ms / 2000ms / 3000ms / 4000ms / 5000ms  Skill_2
追踪触发 = 追到目标后触发		 Skill_3
消亡触发 = 技能体被销毁的时候触发            Skill_4

消亡增加了一个条件：追踪是否消亡

消亡条件为四个独立开关：
20 消亡-次数，默认 true；21 消亡-追踪消亡，默认 true；
22 消亡-施法者死亡，默认 false；23 消亡-目标死亡，默认 false。
最大持续时间到期也会消亡。
本例若“消亡-次数=true”，第五次作用后约 5000ms 即消亡；false 时可继续到 5200ms 到期。

四类技能 ID 参数（12/14/16/18）使用 Skill_1～Skill_4、空值或 0 时，读取 Summon 表对应字段。
需要纯表现时，将对应 Summon 表四类技能置 0，且编辑器不另外配置有效技能 ID。
仅把“追踪目标”设为“无”不能代替清空四类技能。
